M1: ascending-depth deterministic argmin; evaluate uniqueness using all labels within numerical tolerance of J_min. M2: true-depth rank=1+count(J(z)<J(z_true)) using exact saved values, with tolerance-aware rank reported separately and never substituted into H1 Gate. M3: DeltaJ_second=min_{z!=z_true}J(z)-J(z_true), negative allowed. M4: DeltaJ_neighbor=min available true+/-5 labels minus J_true. M5: K_z=J(true-5)-2J(true)+J(true+5) for interior truths. M6: strict interior J_i<J_prev and J_i<J_next; endpoints report separately, ties create no strict local minimum. M7: if dynamic range>numerical tolerance, J_norm=(J-J_min)/(J_max-J_min); contiguous labels J_norm<=0.5 containing the ascending-label global argmin; W50=max_label-min_label, no interpolation or added bin width. W50 is descriptive and is not a confidence interval; singleton width0 is not zero uncertainty.

Numerical tolerance is not selected from margins: repeat every full profile after cold model reload; independently parse .mod via struct, scalar horizontal geometry, ordered compensated mode sums and math.fsum RMS, using the same observation. Independently reconstruct observation generation too. tol=max(128*float64_eps*max(1,max_abs_profile_J),10*maximum_absolute_repeat_or_independent_profile_or_observation_difference).
