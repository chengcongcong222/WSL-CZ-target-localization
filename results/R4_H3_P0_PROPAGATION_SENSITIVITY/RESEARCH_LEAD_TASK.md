## 关键新发现：失败主要来自检测门限，而非响应方向估计

我重新聚合了保存的 `EXTRACTION_SUMMARY.csv` 和 `LOW_ENERGY_FAILURES.csv`，将质量未通过分成两类：至少一个频率／快照块未检测到；或者全部块已检测，但空间投影误差超过0.1。

| K  | 质量未通过 | 含未检测块 | 全部检测后仍有方向误差 |
| -- | ----- | ----- | ----------- |
| 1  | 979   | 847   | 132         |
| 8  | 258   | 258   | 0           |
| 32 | 240   | 240   | 0           |
| 合计 | 1,477 | 1,345 | 132         |

这意味着：K达到8以后，当前所有未通过单元都是检测阶段未放行，而不是已经检测到的空间方向估计超过冻结误差阈值。

K=32时的240个未通过单元，全部来自5%固定绝对噪声底条件：

| 场景  | K=32，5%固定底质量通过 |
| --- | -------------- |
| H01 | 144/144        |
| H06 | 48/144         |
| H12 | 0/144          |

相反，在K=32时，其余三种噪声条件——1%相对、5%相对、1%固定底——均为432/432通过。

所以不应笼统写成“增加样本也无法稳定提取”。更精确的结果是：

有限样本空间方向提取已在若干理想信号条件下达到冻结质量标准；主要障碍集中于弱场、较高固定噪声底，以及当前非常保守的检测规则。

这里还发现一个直接影响后续设计的统计问题：当前检测量为

\\[ T_K=\operatorname{tr}(\widehat R_n^{-1}\widehat R_y), \\]

检测阈值取 \\(N\cdot256/(256-N)/0.01\\)，并不随K增大而降低。增加K可以降低样本协方差的波动，但不会持续增加这个平均能量统计量的期望。某些信噪条件即使K继续增加，也可能长期低于该固定门限。

因此，K=8到32的通过数几乎不变，不能直接解释为H3垂向信息已经达到物理极限。

## 下一阶段的研究判断

我建议接受G2E的冻结负判定，但不再围绕当前压缩响应检测器反复调参；将研究主线转向H3的传播未知量敏感性。

有三点依据。

第一，G2E的失败主要是预注册检测规则造成的门限未通过。该规则统计上有保守的虚警控制依据，但并不是样本数增加时能够持续积累检出证据的最优检测器。未来可以另设预注册、具有K依赖关系的似然检测对照，却不能事后降低旧阈值以改写本轮结论。

第二，当前B1和B2的提取质量通过数分别是1236/1728与1233/1728，几乎相同。这并不推翻H3-G0中垂向采样的2.34–4.47倍局部深度信息增量；只是说明空间响应提取质量并不是检验深度信息增益的替代指标。

第三，比提取器本身更根本的限制仍然存在：C1b只覆盖固定阵元频响未知，C1g自由模态增益会吸收源深信息，而完整RC2水平支持尚未建立。即使将5184个提取单元全部做到质量通过，也不能自动形成可信的测深能力。

因此，现阶段的优先级应是：

先检验受物理参数约束的传播不确定性会消除多少垂向深度信息，再讨论是否值得建立更复杂的检测与连续深度估计器。
