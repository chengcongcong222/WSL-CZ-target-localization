# 已存4500条有限标签诊断：只读联合剖面

## 规则

输入唯一为G0 FINITE_HORIZONTAL_LABEL_DIAGNOSTIC.csv。逐scene/resource/noise/calibration，把每个深度标签的既存分数在25个节点取最小值；第二版本只删除(dr,dv)=(0,0)，保留其余24个节点。C0与主C1b均报告，保留B0/B1/B2、所有镜像和两个噪声条件。

标签180/190/200/210/220 m；分数是原G0 nominal tangent log/phase chart的1%噪声归一化范数，不是真实有限样本似然，也不是重新联合拟合非线性gain。相同分数按dr、dv及深度的确定顺序保留来源；每行回指原CSV行号及输入哈希。不用新的传播、评分、真值加点或场插值。5%刻度可按原设计分数/5表示，但不会据此登记新的显著性或误判门槛。

输出FINITE_DEPTH_PROFILES.csv和FINITE_PROFILE_SUMMARY.csv保留所有标签、中心剔除版本、最低与第二标签间隔、近邻候选及补偿(dr,dv)。间隔和比值是描述量，不划一个事后“近似等价PASS”。离散候选表不能证明连续多峰数量或全域等价关系。

## 如何解释

包含中心时，各结构的200 m可选到自比中心，分数在浮点零附近。这是构造性结果，不是估计器找到中心或工程恢复证据。

排除中心后，主C1b：B1在两种噪声各6/6标识仍以200 m为最低分标签，即各3/3独立主阵几何；B0、B2均为0/6。这是一条有限表内正向结构线索，不能改写FULL_RC2_HORIZONTAL_SUPPORT_NOT_ESTABLISHED。
