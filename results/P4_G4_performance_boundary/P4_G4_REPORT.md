## 1. 方法

- **候选集合观点**：不强迫唯一点估计；输出 posterior width / contraction / truth retention / UNRESOLVED。
- `contraction_j = 1 - width_j / prior_width_j`；多峰保留。
- 基准 **B0**：r=50 km，θ0=0°，z=200 m，v=2 m/s，**ψ=5°（开放几何）**，T=600 s，σθ=0.1°，turn=0，S1，SNR=10 dB。
- LIN 仅作运动学下界，不作主性能基准。
- 不做全笛卡尔积；四组核心扫描 + 三档综合场景。
- 阵列不以具体阵长写装备需求，统一用 **σθ** 与 RC3 阵列联合残差参数化。
- 环境仅三档：E0/E1/E2，**单一物理形式**：声道轴深度偏移（E1 +50 m，E2 +150 m）。
- **10%** 仅作 r/z/v 等正值状态参考线；θ/ψ 用绝对角宽度。

## 3b. 结果可信度口径（必读）

P4 采用**候选集合**观点。阅读收缩率时必须同时看 **truth retention**：

| 现象 | 含义 | 对外口径 |
| --- | --- | --- |
| 收缩高 + retain=1 | 接受集变窄且含真值 | 可写为该条件下性能 |
| 收缩高 + retain=0 | 接受集变窄但**未覆盖真值** | 只能写“模型下出现尖峰解”，**不得**写高精度定位 |
| 宽度≈先验 / UNRESOLVED | 该维在本条件不可辨识 | 写功能边界，不加特征硬抬 |

本轮扫描中的具体注意点：

1. **C-L**：RC2+RC3 后 n 很小、r 宽度显示 0 km，但 **retain_r=0** —— 网格尖峰解未含真值，**不能**解释为困难条件下测距成功。
2. **C-U**：高 SNR + 长 T + 大转角时，声学特征阈值可能偏松（n_RC3>n_RC2），r 仍 UNRESOLVED；属理论模型/接受准则边界，不是“上界条件反而更差”的装备结论。
3. **source×SNR**：部分高 SNR 格点 r 收缩弱，与特征归一化及网格离散有关；趋势解释以 **T 足够后 CZ 轮廓可压 r 候选** 为主（T≥300 s 时 RC3 相对 RC2 的 r 收缩更稳定）。
4. **深度 z**：z=200/220 m 时 contr_z≈0、宽度≈先验 100 m，r–z 相关中等负相关 → **传播未给出可靠独立深度约束**（UNRESOLVED），且存在 r–z 耦合风险。
5. **LIN / RC2 测距**：与 P2 一致，RC2 在冻结机动下**不能**给出实用距离约束（本包主结论保持）。
6. **10% 参考线**：仅对 r/z/v 标注；C-L/C-M 中部分 ten_pct 标志与 retain 并存时，以 retain + 宽度为准。

因此 **G4 = `G4_PARTIAL_BOUNDARY_WITH_UNRESOLVED_STATES`** 是诚实终态：五维边界已形成，但存在未辨识/不可信尖峰格点，不得包装成全维高精度。

## 4. G4 五句话（甲方）

1. **距离 r**：主要由 **RC3 会聚区传播** 约束。B0 下 source×SNR 时 r 候选宽度约 4.000–10.000 km（S1/S0）；C-U 上界场景约 15.000 km，C-L 困难场景约 0.000 km。RC2 在冻结机动下**不能**给出实用测距。
2. **方位 θ**：由 **RC2 连续方位** 约束。要 θ 收缩明显，需足够 T 与较小 σθ：σθ=0.02°、T=1200 s 时 θ 收缩约 0.900；σθ=0.5°、T=300 s 时约 0.600。
3. **深度 z**：在第一会聚区传播模型下，z 候选宽约 100.000 m，contr_z≈0.000，r–z 相关≈-0.310。若 contr_z 偏低或宽度接近先验，则 **传播未提供可靠独立深度约束**，与距离存在耦合风险；深度功能边界按 UNRESOLVED 写，不加新特征。
4. **速度 v**：RC2+RC3 联合后，v 候选宽在 C-L/C-M/C-U 约 0.000 / 0.000 / 2.000 m/s；距离–速度补偿主要靠 CZ 轨迹压缩，而非 Doppler。
5. **航向 ψ**：靠 **RC2 方位变化率 + 几何/机动** 在长 T、开放几何（ψ≠0）下可辨识；传播对纯 ψ 增量有限（G3 已示）。C-M ψ 宽约 0.000°，C-U 约 30.000°，C-L 约 30.000°。
