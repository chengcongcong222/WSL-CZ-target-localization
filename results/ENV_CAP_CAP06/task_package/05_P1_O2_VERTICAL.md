# P1：O2同步多接收深度相对功率——真实新信息还是差分增益假象？

## 科学问题

同时不同深度两通道窄带接收功率（背景扣除以后）可定义

\[
 d_i(t)=10\log_{10}\frac{I_i(t)-N_i(t)}{I_0(t)-N_0(t)}
 =10\log_{10}\frac{H_i(x,e,t)}{H_0(x,e,t)}+\gamma_i(t)-\gamma_0(t).
\]

同源功率会被消去，但通道gain、AGC、不同路径/环境依赖、有限窗噪声仍在。弱场或`I-N≤0`必须标记缺测，不能强取log；共享参考使比值相关，禁止当作独立通道信息。

**核心明确**：H3的2.34–4.47倍复响应局部深度信息只说明增加垂向通道可能有价值，不是本轮相对功率的收益。O2需要独立的、物理一致的功率响应模型和提取验证。

## P1-a：零控制及数学能力边界（独立于传播物理资格）

冻结以下互斥增益条件：

- G0 已知差分增益的理论对照，明确独立标定成本。
- G1 未知但跨时恒定差分增益。
- G2 未知常数+缓慢线性差分漂移（联合估计/剖面）。
- G3 每个历元自由差分增益，必须零增量。
- G4 只有共同AGC未知但**差分增益固定**，用于检查可消的公共项。

噪声主档可建议0.25/0.5dB和相关系数ρ=0/0.9作为假设性研究等级；不能自动把旧CZO04的0.25dB当设备能力。垂向接收深度、每路AGC处理位置、噪声底、差分gain时间常数与源方向性均独立入未知量。状态`[r,theta,z,v,psi]`与环境扰动一并处理，不锁真z/e。先输出解析Jacobian、Schur/nullspace和全自由零控制。

## P1-b：前向与信号链资格审查

1. 登记信号假设：单频相干稳定CW、可平均宽带随机源、或有限非相干路径系综，**三者不能互相冒充**。非相干I类SHD只能作为其明确适用的期望强度条件参照。
2. 若使用新第一CZ声学前向，必须来自同一WOA SSP、源/收深、边界/损耗、频率身份；对垂向差分功率（通常比绝对声级更敏感）进行网格/束数/接收插值、边界贡献及独立数值交叉审计。不得使用旧T2失败复场或将complex64转为complex128冒充精度提升。
3. 若试图从相干CW复场生成接收，先评估直接复场功率与独立无关相位平均的差异，记录独立样本数/积分频带/统计窗口；绝不能直接使用已存I曲线生成单CW相干功率并声称信号级通过。
4. 如果没有可靠、符合当前第一CZ身份的功率/复场生成器：记录`O2_FIRST_CZ_FORWARD_NOT_ADMITTED`，后续只许合成**明确的数学玩具模型**进行处理器、比值和增益退化验证；该结果标`SYNTHETIC_MECHANISM_ONLY`，不得报告第一CZ深度P95。

## P1-c：非oracle提取及信息

生成端可知道功率、噪声与增益，提取端只拿`receiver_public`原始有限窗接收样本、AGC元数据（若该条件确实登记为已提供）与背景参考窗。禁止送入真深度、真源谱、真声道标签。评价：比值偏差、低信噪/负扣噪、相关噪声、缺测与错误关联、时间抖动、calibration drift、输出拒判。

在有资格的样本上分别求局部条件增量以及全候选集合（多支不删），并行列G0/G1/G2/G3/G4；用同一噪声实现公平对照。若没有可检验的真实新增信息，记录结构零/弱证据，不用更长孔径、更大垂向孔径或更强先验事后救活。
