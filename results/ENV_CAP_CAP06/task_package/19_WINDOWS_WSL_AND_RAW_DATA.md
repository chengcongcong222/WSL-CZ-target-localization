# Windows / WSL执行建议与D盘原始数据处理

- 用户环境为Windows+WSL(Ubuntu x86_64)；既有代码使用NumPy/SciPy/gsw和Windows或WSL上的Acoustics Toolbox。先打印实际版本和架构，不把旧Windows二进制默认为新的双精度求解器。
- 发现D盘：在Windows优先`D:\\...`，在WSL通常`/mnt/d/...`，但需以实际挂载检查为准。**不可硬编码先前用户项目路径**，亦不可将旧D盘归档误认为当前一定存在。
- 用独立D盘新目录存储模拟接收信号、校准/导航伪观测、临时PSD/互谱、求解器大数据；Git只存源代码、小表、图、冻结配置及大文件SHA索引。原D盘数据只读、不移动/重命名。
- 若无法取得历史D盘大数据：优先从当前仓库冻结资源复建输入，核对SHA；无法复建时标记SOURCE_UNAVAILABLE，停止依赖该文件的观测层，但另一支线继续。不得把路径字符串当作数据已存在。
- 准备venv安装必要依赖前记录Python/包版本与许可证。禁止自动下载需要权限的专有数据或设备SDK。注册外部声学求解器完整命令/二进制SHA及返回码；Fortran STOP/rc=0不代表科学准入。
- 进程树RSS监控、科学单元超时、CPU/数据上限及停止标记必须生效。时间窗长的合成数据采用按案例流式保存，避免一次性占用过多内存。
- 旧项目可能含多次STOP和Git未跟踪文件；使用独立worktree/clone，不能用`git clean -fdx`或`reset --hard`清理用户数据。
