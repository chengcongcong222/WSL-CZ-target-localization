# P4：性能—资源反推、科研创新与项目申请证据收口

## 四资源配置的独立成本向量

对每配置记录

`C = (#主阵通道, #新增垂向通道, #辅助节点, #辅助阵元, 布放基线/前置, 观测秒数, 导航误差及来源, 校准工序与稳定期, AGC/噪声底可追溯性, 时频/关联条件, 计算预算)`。

这些是**研究资源指标**，不是报价或已有硬件台账。无法核定的采购/能耗/海试可用性保持`UNKNOWN`；独立先验、已知源频、已知方位符号及正确关联也须进入成本。

## 倒推的合法层次

- `MATHEMATICAL_NECESSARY`：可追溯解析零空间/不变量条件，例如逐时自由差分增益使O2零信息、辅助水平方位z零列。
- `SIMULATION_CONDITIONAL_INFORMATION`：在明确声学/仪器模型、误差与资源假设下的有效信息或有限候选差异，不是取得实际精度。
- `TESTED_CONDITIONAL_FEASIBLE`：只有经生成→非oracle提取→全候选→独立留出的完整条件试验通过相应需求，才可填写。
- `TESTED_INFEASIBLE_UNDER_REGISTERED_MODEL`：限定于当前失败模型、样本、算法和预算，不能推出所有方案不可行。
- `UNKNOWN_OR_UNTESTED`：前向、提取、资料或性能门未过。不得填0误差或使用Inf作为未测试标记。

对于有限集合，Pareto仅限**通过同一级证据Gate**的配置；不同算法、不同资源、不同信号先验不得假定同成本。给“资源—五维信息弱方向”表比给一个伪统一分数更重要。示例精度档是内部比较，不做用户验收承诺。

## 创新性自审

不应将同频功率归一化、简单差分、增加阵元、扩大基线、查阅先验或传统信息滤波算作核心新算法创新。申请创新应定位于：

1. 第一会聚区环境先验与短时单阵连续观测共同限定多参数**候选而非直接五维解**；
2. 未知源/校准/环境与多分支共同存在时，**可提取信息如何产生、退化及被补充**的可证伪机制；
3. 在能力与可信证据层级约束下，从目标精度反推**最低必要观测类型/条件**与可行资源前沿，而非虚构实际最小设备。

如果P1/P2未获得正向提取，也应写**拟研究科学问题+目前能够证实的边界**，不将负结果包装为创新已完成。
