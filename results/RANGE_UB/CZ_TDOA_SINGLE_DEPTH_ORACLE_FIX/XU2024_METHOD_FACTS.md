## 到达结构（p.239–240）

- 第一簇：反转声线 + 一次海底反射声线
- 第二簇：二次海底(海面)反射声线
- 接收深度 200 m 时到达时间 ~33.5–38.0 s
- 接收深度 1250 m 时分为四簇（含正/负到达角分离）

## 五类时延差曲线（p.241）

随接收深度近似线性变化。平均斜率：

| 量 | 斜率 |
|---|---|
| τ₂₁ | ≈ 4H/(cR) |
| τ₃₁ | ≈ −2H/(cR) |
| τ₄₁ | ≈ 6H/(cR) |
| τ₃₂ | ≈ −6H/(cR) |
| τ₄₂ | ≈ 2H/(cR) |

**核心：斜率 ∝ 1/R，据此反演距离。**

## 迁移结论

- `CZ_TDOA_PAPER_METHOD_VERTICAL_DEPTH_SAMPLING_CONFIRMED` — 论文方法核心是时延差-接收深度曲线斜率，必须垂直采样。
- `CZ_TDOA_PAPER_VALIDATION_BROADBAND_SIGNAL_CONFIRMED` — LFM/爆炸声源宽带信号。
- `CZ_TDOA_DIRECT_TRANSFER_TO_CURRENT_HLA_NOT_ESTABLISHED` — 单深度 HLA ≠ 垂直 VLA；不能直接套用论文公式。
- 这些数字**只作原文证据**，不作为 E-STD 性能值。
