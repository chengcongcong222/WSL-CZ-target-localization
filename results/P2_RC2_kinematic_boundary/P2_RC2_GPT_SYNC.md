## 2. 关键发现：冻结基准是 RC2 极限几何

用户冻结基准 `θ0=0°, ψ=0°, v=U=2 m/s` 时：

```
xt = r0 + v t,  xp = U t  →  dx = r0, dy = 0  →  θ(t) ≡ 0
```

方位序列与 `(r0,v)` **完全无关**。这是理论事实，不是实现缺陷。
- LIN, σθ=0, T=600 s：接受集 r 宽度≈**15.000 km**（搜索盒全宽），后验σr≈**4.610 km**，r可辨识比例≈**0.00**。
- LIN, σθ=0.1°, T=600 s：r 宽度≈**15.000 km**，后验σr≈**4.592 km**，|Δv|≈**0.215 m/s**。

**RC2 的作用不是完成远距离测距**，而是利用连续方位与平台运动排除部分运动状态、约束方位/航向，并形成仍存在距离–速度歧义的困难候选，供会聚区传播信息继续筛选。
