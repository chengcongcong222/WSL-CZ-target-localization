# B1A truth separation

Read existing accepted B1 observations byte-for-byte. B1A never generates a new observation or uses true depth to choose source samples for prediction. Depth profiler is the unchanged original B1 API (horizontal,observed,models,depth_labels,frequencies). It receives no true depth, case ID, expected depth, Gate, winning label, truth-near optimization or initializer. All21 labels are evaluated unconditionally. Independent score reconstruction has the same truth-free inputs and every21 labels, not a true-depth shortcut.

Authorized conditional state=(50+dr km,0 degree,2+dv m/s,5 degree) is a declared controlled variable. It is not an observation-only horizontal estimator and no upstream ability to reach these errors is assumed. Reference/true z from accepted case metadata enters only post-profile metrics/output evaluation. Complete scores are saved before scientific ranking/Gate decisions. Estimator never receives evaluator output. All486 states are frozen in B1A_LATTICE.csv; no dropped failures, no altered score/frequency/depth label, no mixed SSP or source-level assumptions.

Claims: synthetic matched E0, on-grid depth labels, finite r-v conditioning lattice, fixed theta/psi. Do not call a tested node rectangle a continuous certificate, platform precision, real-ocean performance, end-to-end acquisition/depth guarantee or final accuracy requirement. S7 and S8 are different frequency configurations of the same three scenarios, not independent trials. Historical angle/heading controls remain separate single-factor results.
