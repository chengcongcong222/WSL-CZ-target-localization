# 参数敏感性、性能必要界与非oracle能力验证

## 总原则

本研究应建立“物理上有信息 → 能从录音提取 → 实际算法达到条件精度”的阶梯，而不是只增加SNR/孔径使最终RMSE更好。主背景是**首CZ已准入**的环境。严禁将任意一种条件曲线转换成普遍设备能力，或把oracle模态、真值水平/深度、已知源频传入非oracle路径。

## 1. 预登记敏感性轴（E0锁范围和来源，E2锁可以实施的格点）

| 轴 | 关键量 | 有效范围的来源 | 主要输出 |
|---|---|---|---|
| 环境形态 | 水深、SSP梯度、轴深、季节/位置、底质 | 原始数据或有引用的重建+扰动 | 首CZ位置/宽/峰、模态密度、信息丢失 |
| 源/收深度 | source_z, receiver_z及不确定度 | 合法水深内任务场景范围 | 首CZ敏感性、源深签名、局部不可辨识方向 |
| 相对径向孔径 | Lr,时间/速度与运动几何 | 轨迹与可估运动条件 | Fourier/AR峰可分、深度区间与必要孔径 |
| 频谱 | 频带、持续谱线、可用模式激励 | Yang论文与条件UUV谱线假设 | 模态可恢复数量、频差和错配 |
| 噪声 | 接收SNR、噪声谱/相干性 | 标明假设的观测端 | 提取失败、误判、错误深度区间 |
| 发射源未知量 | f0,线性/非线性漂移,源谱 | 不提供oracle f0，合理漂移合同 | Doppler混淆、虚拟孔径失效 |
| 相位/距离起点 | δ、时钟、源运动/导航不确定 | Yang 2018勘误、设备资料/需求假设 | 深度评分错位、模态相位误差 |
| 空间接收 | 8元14m HLA；4m短VLA；非共线横向孔径；辅助节点 | 资源成本明确 | 局部深度/左右镜像/距离信息互补 |
| 外推质量 | SSP/海深/底质/姿态估计误差 | 气候误差/有引文的统计/参数化假设 | 稳健性、失锁/丢失路径、未知量吸收 |

首轮采用**一因素冻结级别**和最多**两组预登记二因素相互作用**，而不是在九维全网格扫描里找最有利点。每个级别必须有明确数据/物理解释。以前历史的`SNR 20dB`、`Lr 0.6/1.2/2.4km`可作为对照，但不是所有环境必有同样的测量条件。

## 2. 灵敏度的数学定义

观测模型`y=g(x,eta;environment,resource)+noise`。状态`x=[r,theta,z,v,psi]`，未知干扰`eta`含源、clock、海底、SSP、接收位置、阵元校准、模式身份等（按方法实际可观测定义）；用完整联合协方差白化。`Ieff = Jx^H (I - Jeta Jeta^+) Jx`的实问题推广/对应实嵌入，须明确变量尺度和秩阈值；精度弱方向应对未知量投影后判断。

- `local_CRLB`: 只有模型/噪声假设、可估性、无偏局部线性条件；不能当经验分位下界。
- `global_multi_branch`: 搜索和保留全部左右舷、距离与模态匹配的物理分支；数值预算截断的未决域不得删掉。
- `feature_extraction`: 对未知源、噪声、漂移、delta、环境依次解除oracle，保存失败率与错误关联。
- `MC`: 只对正式可提取链输出包含拒判(INF)的无条件分位与校准置信集合覆盖。

未知源/环境使信息降到零是有效科研结果；只测单变量其他参数真值固定时，标`ORACLE_SINGLE_PARAMETER_UPPER_BOUND`。

## 3. 事前设定的研发精度等级

推荐用`示例需求档`而非“甲方既定联合<10%”。E0冻结文件记录如下建议或有据调整并说明：
- `z`: 5m/10m/20m（绝对误差、区间覆盖与类别误判各自统计）。
- `r`: 1%/5%/10%（或绝对km，随CZ距离尺度报告）。
- `v`: 0.1/0.25/0.5m/s（绝对），另外百分比仅次要。
- `theta`,`psi`: 用角度/圆周误差及左右舷错误分支率，示例0.2°/0.5°/1°分开设。
- 联合指标：逐参数事件与同一次五维联合事件必须分开；在某参数`NOT_EVALUATED`时联合指标也`NOT_EVALUATED`。
- 统计信度：建议探索性P90/P95和90%/95%区间覆盖；无新抽样时不能输出P95。以上为**研究扫描的坐标刻度**，不约束项目最终必须达到哪个等级。

## 4. 具有可审计因果意义的对照

- 同一环境同一生成观测，比较oracle-mode Fourier / oracle-depth control / nonoracle Yang / nonoracle MMAR；若输入资源不同要显式对照成本。
- 同一段原始声压派生的谱峰/相位/方位不算独立采样数；有联合协方差或互斥算法比较。
- 保留解析零信息：平面波距离/深度0，缺横向孔径时左右镜像0，未知源频/独立节点漂移吸收Doppler，模态独立自由增益吸收深度。
- 对可提取方法使用先冻结状态和随机种子，开发/留出独立，不按真值匹配成功频率挑选谱线/模式。
- 环境族作为独立分层，平均成功不能掩盖某一环境完整失效。
- 若局部FIM有正信息但提取无法恢复，标`UPPER_BOUND_ONLY`; 如提取可用但全局多峰严重，标`MULTIBRANCH_LIMITED`。
