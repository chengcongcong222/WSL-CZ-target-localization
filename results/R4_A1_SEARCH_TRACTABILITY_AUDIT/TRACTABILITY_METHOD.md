## Independent raw execution and accounting

Each solver/case/budget/depth branch constructs a new ExactObjective, BudgetObjective, optimizer call/state and exact cache. The shared fixed modal model carries no recovered-state initialization.

Each branch saves termination_reason, solver_success/message, native exception_chain, execution_valid/reason, all four required counters, attempt/refusal counters, cap/trigger, direct top-state/bearing score, elapsed_seconds and n_validation_exact_forward_evaluations. The complete raw callback ledger is stored separately. Every feasible exact cache witness is extracted without optimizer reevaluation or local polish. Each case combines all 21 branch witness sets, selects the exact-score minimum with deterministic state/depth tie order, and reports strict recovery separately from execution validity. ## Gate sequencing and stop rules

The Gate is threshold-hit / witness convergence, not a local-stationarity certificate. T3 must not introduce a T2-unmatched distinct subthreshold witness cluster. Raw convergence needs 21/21 in each solver, and dual-solver comparison runs only after both pass. Any raw-convergence or dual failure returns A1_SEARCH_TRACTABILITY_NOT_ESTABLISHED and prevents fresh generation. Strict exact-alias reconstruction has its own stopping finding. No T4, option increase, tolerance change, replacement solver or new local-polish algorithm is introduced.

DEVELOPMENT_RELEASED=False guards the CLI, real execution, runtime loaders, family runner and default branch objective before scientific input/model loading. Dependency injection is only for explicitly synthetic unit-test wiring; tests with the real objective use synthetic noiseless bearings and arbitrary zero TL, never the 21 development observations. FRESH_CONFIRMATION_RELEASED=False independently forbids generation even if synthetic test decisions pass; development failure returns NOT_REACHED_DUE_TO_DEVELOPMENT_GATE without calling a generator.
