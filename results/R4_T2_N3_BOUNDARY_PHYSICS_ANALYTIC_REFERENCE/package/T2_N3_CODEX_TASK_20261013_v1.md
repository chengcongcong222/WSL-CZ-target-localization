## 2. 独立解析参考——先验数学事实，不用旧数值场作为真值

**只适用于本次新造的等声速、无损、水平分层理想波导**：水深`H=5000m`、`c=1500m/s`、`ρ=1g/cm³`、海面自由（压力释放），两种底部边界各单独跑：

- `PR_R`：下底刚性，`p(0)=0, ∂zp(H)=0`；`μ_n=(n+1/2)π/H`, `n=0,1,...`。
- `PR_PR`：下底压力释放，`p(0)=p(H)=0`；`μ_n=(n+1)π/H`, `n=0,1,...`。
- `φ_n(z)=√(2/H)sin(μ_nz)`；`k_n=√{(2πf/c)²−μ_n²}`，仅保留**真实水平传播**`μ_n<2πf/c`的离散模态。`cp_n=2πf/k_n`，CHIGH仅保留`cp_n<CHIGH`；高于CHIGH及截止后的传播模态不得偷偷填入该窗。
- 独立解析径向参考采用 `(-iπ) H_0^{(2)}(k_n r)`；与旧KRAKEN项目采用的远场形式 `√{2π/(k_nr)} exp(-ik_nr-iπ/4)`比较前在所有空间位置只允许**公共复数比例**，不允许逐模式、逐阵元调系数。参考仅包含水平传播模态，未包含极近场/倏逝模式，故只在已登记45–60km远场对比。

同包预生成的`ANALYTIC_WAVEGUIDE_MODE_COUNTS.csv`、`ANALYTIC_WAVEGUIDE_WINDOW_SHAPES.csv`、`ANALYTIC_EXACT_RADIAL_VS_FARFIELD.csv`来自本任务的**非KRAKEN解析程序**`t2_n3_analytic_reference.py`，可在本机无需声学求解器复现；以文件SHA锁定参考，跨SciPy/OS浮点CSV不强求字节相同，而是逐指标在`1e-8`以内吻合。冷审计不得简单复用主函数，必须另用不同的本征根验算/投影求值。解析程序不能导入任何R3/H3/KRAKEN物理MOD文件。

频率：**201、283 Hz**。CHIGH集合：**1800、2400、4000m/s**，另外解析程序单独给出 `ALL_PROPAGATING`作为**数学参照**（绝不称4000已完整）。当前计算的`PR_R`正确解析模态计数分别为201Hz `741/1046/1242/1340`，283Hz `1043/1473/1749/1887`；`PR_PR`正确计数也由同包CSV冻结。原E-STD之模式数不同，不得要求它等于均匀波导。
