# T2-N3-PREC1 本会话独立研究记录

## 结论（当前完成的额外计算，不是原N3科学Gate改判）

使用 GitHub `chengcongcong222/WSL-CZ-target-localization`、固定提交 `8ee2bd53fe1b7a50725833e6c7b5c5dea35fbe23` 中两份原始 MOD 二进制文件：201 Hz、刚性底、CHIGH=1800 m/s（741模态）、CHIGH=2400 m/s（1046模态）。直接解析二进制MODE记录、复本征函数及 float32 波数，保持原阵元坐标与传播几何，对 P01–P05 × 4资源 × 2窗口共40项四臂替换作了新的模型内分析。

波数审计：1,787/1,787 条 KRAKEN-MOD 储存水平波数与等声速解析波数 `np.float32(k_analytic)` **逐条完全一致**。以58 km计算，最大绝对波数误差约 `2.9755e-8 m^-1`，单模态相位偏移上限约 `0.001726 rad`。这证明存档波数的差异可由单精度舍入解释，不能凭此说求解器本征根精度不够。

固定 P04，201 Hz，CHIGH=2400：

| 资源 | N3原MOD与解析基准误差 | 仅替换解析波数后的误差 | 仅替换解析模态函数后的误差 |
|---|---:|---:|---:|
| A0：8元水平 | 0.2016% | **0.0229%** | 0.1818% |
| A_P4M：8元整体倾斜 | 0.2089% | **0.0100%** | 0.2044% |
| B1_V4：12元短垂直 | 0.2215% | **0.0282%** | 0.2082% |
| B2_DUP：12元同深 | 0.2045% | **0.0241%** | 0.1842% |

其中原MOD误差取自N3封存表；两类替换误差是本轮读取原MOD计算的结果。全40项的“仅替换波数”误差均小于0.2%；仅替换模态函数时，P04的A_P4M与B1_V4仍大于0.2%。整个形状误差具备相干相消，不能将两个“替换后下降的百分比”做加和或当作严格的方差贡献份额。

**不同口径控制：**本轮C0–C3采用与已保存 MOD求和相同的远场柱面因子；原N3用解析 Hankel 径向核做参考。由于两种解析核在45–60 km有微小差别，本轮手工计算C0误差与原N3差值小于 `3.8e-7`（无量纲的绝对形状差）。作为独立验证，在本会话用SciPy以纯解析模态函数+float32波数另外复算C2的P04四种阵型，对原MOD读取计算的C2结果最大差异小于 `3e-11`。

## 证据边界

本轮没有新 KRAKEN、FIELD、FIELDS、SCOOTER、录音、DFT、蒙特卡洛或优化。原N3四项失败记录不被事后回溯改为PASS。新发现仅证明：在理想**等声速**波导里，一旦人为提供解析双精度波数，就可以消除已观察的P04门槛超限；不能将解析根迁移到历史E-STD真实变声速场，也不能处理CHIGH缺漏、海底参数未知或实际接收精度。

已编写完整Python分析器与不复用分析器数值例程的独立二进制冷审计器。它们先通过了独立生成的**合成MOD格式单元测试**（1,991项审计检查，0失败）；这不是把原MOD的正式冷审计冒充已完成。完整实际MOD冷审计由本地Codex执行后回传。

## 下一研究判断

PREC1主要修复**精度来源可辨识性**，不是修复物理传播模型。若本地冷复核确认，下一次需要区分：如何在非等声速传播模型中获得高精度水平波数、如何保证宽CHIGH模态完整性、以及是否有足够客观海底参数使T2阵型进入性能比较。优先处理前向物理和数值合同；不得把N1的旧1800窗口优势套到扩窗声场。
