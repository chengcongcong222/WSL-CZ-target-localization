# Estimator input exclusion and execution boundary

The representation accepts only real M0 level arrays and the frozen frequency/time metadata. The support API accepts immutable bearings, 12 coefficients, an unchanged observation-side RC2 cutoff, fixed model inputs, tolerance, resolution and a strict budget. Dataclass signatures reject all additional fields. There is no case ID branch, archive loader, state warm start, local optimizer or estimator import of an earlier A1 experiment.

Static audit parses the representation, support and model ASTs. No identifiers or argument names `truth`, `truth_range`, `truth_state`, `errors`, `old_recovered`, `old_best`, `oracle`, `basin` occur in those modules. No evaluation/old experiment import or observation archive string is present. Complex values occur solely inside modal pressure prediction; the observation API rejects complex inputs. Source-depth labels are the full finite profile, not an evaluated reference depth.

The evaluation module is separate. Its `retention` helper is decorated by a ContextVar runtime guard. Both a full support run and the direct certificate entry activate the estimator scope. Any call to that helper inside those entries raises immediately. Tests deliberately attempt that leak. Analytic known-feasibility and calibration states are confined to tests or the PRE-RUN audit; they are fixed domain corners from the pushed policy, not P/Q seeds.

The calibration runner checks local HEAD and remote main against the policy commit before computing any fixture. It verifies policy bytes and the frozen input hashes. It imports no historical science module and opens no observation array. Its only scientific-model reads are the three frozen modal files. Integrity inspection of the existing archive uses ZIP member names and NPY headers only; no numeric array payload enters the representation, model, calibration or support. The 21 manifest identifiers/count are metadata only.

`r4_cz_envelope_development.py` has DEVELOPMENT_RELEASED=False and an entry hard stop before any read. It contains no numerical development implementation. A future release requires a separate research-lead instruction; changing the flag alone does not install an experiment driver. N1 and other representations have no fallback path. Fifteen archived noiseless cases remain regression-only and unrun here; FIX2's 24 cases are unrun; fresh is NOT_GENERATED.

Current counters: 21-case numerical feature/search runs=0; no CASE_SUPPORT_METRICS, RETAINED_RANGE_INTERVALS, scientific case scores or recovery output exists for this stage. PRE-RUN calibration numbers and analytic test values are not scientific acquisition evidence. Accepted R3/A1/FIX1/FIX2/tractability and Gate0-3 evidence is checked byte-for-byte; only master plan/ledger receive zero-credit appendages.
