# 研究增量和可靠输出指标

不把连续深度误差<10%当唯一准入标准，不用局部FIM的倒数直接作定位精度承诺。当前没有以下指标数值。

| 指标 | 定义与公平比较要求 |
|---|---|
| 深度有效信息 | 同源谱/校准/水平未知量和原始噪声下，比较原HLA、HLA+垂向及同通道数共深度控制；同时报局部不可辨方向、最弱方向和提取损失。不只用尺度依赖trace |
| 水平误差耐受 | 对注册完整支持域及嵌套误差域报告非平凡深度集合/分区保留，比较原B1A有限域诊断；不按结果收窄r/v、不假设单调 |
| 无mode-ID能力 | 提取器只获得原始接收与可公开观测坐标，不给真实k/φ/身份；报组定义稳定性、错组/泄漏和拒判率 |
| 短孔径代价 | 在相同频带/时长/阵元数/源级/校准假设下比较孔径；新垂向通道增益与纯阵增益分开。4 m只是待证候选 |
| 未知源谱鲁棒 | 任意公共S与整体级别不改变无噪统计量；实际噪声下按登记谱/接收能量分层报告。未知相对频响C1b单独评价 |
| 深度集合覆盖 | C(y)可为多个区间，要求在注册目标/水平/环境/校准范围内P(z∈C)≥1−α；同时报集合测度、全域输出率、空集率。全域集合虽覆盖高但无信息 |
| 分区错误率 | 类别边界先登记、允许多类/拒判。区分无条件错误概率、条件于已判决的错误率与判决率；拒判不能消失于分母 |
| 资源归一比较 | 各方法记录接收孔径、通道数、带宽、1200 s时长、水平/环境/时钟/源频率先验和成本；超出原论文条件只能称迁移试验 |

覆盖目标建议先采用1−α=95%的设计目标，不能用本轮6个典型场景证明。下一冻结需给统计校准及误差上界方法，并区别有限节点和连续状态域。若只有离散标签，可报标签集合覆盖，不能称连续深度区间。180–220 m缓存标签不能支持广深度水面/水下性能；未来该问题需要独立注册覆盖整个预定深度域。

与论文的比较分两层：原论文条件的忠实方法/资源复现，和当前E-STD第一CZ合同下的方法对照。Yang须加入2018 δ处理，Liang必须AR→Hankel且无真值身份，Xu须锁定有限带宽幅度谐波与短阵近似，Zhu须保留其距离补偿/角跨度约束。做不到原条件复现就标NOT_REPRODUCED，不用其报告精度作本项目基线数字。

可严肃研究的突破：在源谱和频率响应未知、完整水平候选仍宽的情况下，以远小于既有VLA孔径形成非平凡且可靠覆盖的深度类集合。该命题目前仅为假设。若需要新增共钟/深度标定/环境先验，增量结论必须附带这些条件；深度突破不能补记为速度指标通过。
