# HLA-H1 method and scope

This is the delegated 20261009 task, not an old acoustic-search repair. Source profiling is an explicit dB feature likelihood. Each window uses orthonormal time contrasts (61/60 samples) and, for M1, two orthonormal frequency contrasts. The norm equals double-centering SSE; projected noise covariance is sigma_L squared identity. M0 has 357 acoustic coordinates; M1 has 238. Combined absolute chi-square thresholds have 478 and 359 degrees of freedom. Depth is one shared label, never independently selected per frequency/window. Neither state nor depth fitting removes additional threshold degrees of freedom.

BEARING: 121 signed bearings; M0: fixed spectral offsets only; M1: offsets plus arbitrary common temporal amplitude; ORACLE: source-variation subtraction only in a separate finite-grid branch. Every accepted horizontal index, profiled depth and score is saved. Oracle does not supply main or offgrid initial conditions. Generator and estimator APIs are separate, and offgrid estimator reads observations only.

The main common-source models are S1 and S2 at 0.25 dB. Source changes and Gaussian innovations are paired across all methods and scales; 192 independent base pairs, not 2304 independent experiments. Frozen descriptive A/B signals are applied separately to S1/S2. We conservatively require at least four geometries satisfying both A and B for both source shapes to select the conditional-gain classification. This supplements, and does not replace, all per-geometry signals. Empty-set widths are undefined, not zero; a zero finite width means one grid label. Best rejected points are labeled safe-pool-only, not globally certified minima.

The full 114576 grid by 21 depth cache is observation-independent. Main pools use the largest combined threshold for nonnegative bearing lower-bound exclusion. Near-threshold states within a validated-scale 0.001 dB projected-error buffer are all-depth direct rebuilt. Direct best-point verification is performed. This buffer is a numerical diagnostic, not a global uniform interpolation certificate; results remain a conditional finite-grid mechanism study. Offgrid seeds use exhaustive original-grid/all-depth observed scores in all 16 range strata, two distinct h,z entries per stratum (grid spacings exceed fixed dedup scales). One bounded least-squares configuration uses normalized horizontal states, frozen numerical two-point Jacobian, 150 evaluations and 1e-9 tolerances; no direct polishing/restarts. All terminal candidates are direct reprofiled over 21 depths and retain the original depth result. These exported envelopes are not continuous confidence regions.

Likelihood maximization over unknown source spectra is a general principle discussed by [Dosso and Wilmut (2012)](https://pubmed.ncbi.nlm.nih.gov/23039424/), DOI 10.1121/1.4730978. Our specific dB model is independently defined here; no full paper replication or projection innovation is claimed.

Classification does not certify hardware, sea-trial coverage, signal extraction, depth precision or arbitrary source-spectrum robustness. R4 remains zero. Frozen historical SSP, H3 and RC2 conclusions remain unchanged. No propagation executable is invoked.
