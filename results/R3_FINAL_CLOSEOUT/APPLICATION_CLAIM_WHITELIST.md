# APPLICATION_CLAIM_WHITELIST

UTC: 2026-09-30

## 可写

1. 利用连续方位维持运动学候选，并引入会聚区多频传播结构进行递进式候选压缩。

2. 数值结果表明，小幅平台转向形成的运动基线与多频传播约束存在协同，可在已测试场景中切断部分单频残留的距离—深度别名。

3. 多频优势来自不同频率传播结构对错误候选的互补排斥。

4. 方法对正确跟踪后的线谱频率漂移表现出较好的 tested tolerance，但对环境声速剖面失配较敏感。

5. 在理想匹配环境下，201+235+283 Hz 三条线谱配合 15° 转向可在测试场景中切断三个目标深度的距离脊线。

6. 深度作为 nuisance variable 进行 profile，不需要精确已知目标深度。
