# NUM03：稳定Snell积分参考推导

约定水平层化介质、深度z向下、发射掠射角alpha相对水平方向。Snell常量p=cos(alpha)/c(zs)，令cp=1/p。单程水平增量为

`dx = c(z) dz / sqrt(cp^2-c(z)^2)`。

首深回返距离R是源深到首深转向点积分的两倍。若此前已碰海底，则记录该边界分支，不能称零边界深回返；仍保留其到源深的镜面回返距离作为完整角域诊断。该模型不计算传播幅度或能量。

## 1. C-linear解析原函数与稳定表达式

一段[a,b]上c(z)=ca+g(z-a)，g非零时

`I = (sqrt(cp^2-ca^2)-sqrt(cp^2-cb^2))/g`。

直接相减在端点值相近时有消去。利用平方差并将g=(cb-ca)/(b-a)消去，得到

`I = (ca+cb)*(b-a) / (sqrt((cp-ca)*(cp+ca)) + sqrt((cp-cb)*(cp+cb)))`。

这个表达式也覆盖g=0的有限非掠射情形，不需要用两个近似相等的平方根相减。在简单转向端明确使用cb=cp，避免用浮点根重新求值产生错误的非零端点项。平段且cp=ca=cb为掠射退化，不能硬赋有限距离。该解析公式没有求积截断误差，但仍有浮点、输入和根的误差；代码中的零求积估计不表示真实总误差为零。

## 2. PCHIP在全路径应用同一转向变量

PCHIP保留原SSP节点并在相同节点上构造C1分段三次多项式。对实际深转向zt，令`u=sqrt(zt-z)`；每个SSP段都转换为u区间，绝不只处理最后一段。

`I = integral 2u*c(zt-u^2)/sqrt((cp-c)*(cp+c)) du`。

这样，转向刚越过节点时，前一段也在同一个平方根坐标下积分。所有SSP节点仍是明确积分分界，不跨梯度或高阶导数变化盲目求积。

在含简单转向点的段，三次多项式给出精确的代数恒等式：

`cp-c(zt-u^2) = u^2 * (c'(zt)-c''(zt)*u^2/2+c'''*u^4/6)`。

将u约去后端点有限，不以两个约1500 m/s的数相减估计微小差。其余段选声速较大的端点作锚点，以端点差加多项式Taylor增量计算cp-c，利用PCHIP单调分段避免无谓消去。若先遇海底，没有真正的转向奇点，仍用该段端点平方根坐标并显式处理小正端点差对应的尺度。

根在段内局部坐标x=z-z_j中求解`a*x^3+b*x^2+d*x+(c_j-cp)=0`；避免每次以完整声速值减cp形成残差。无损名义SSP并不因此成为已认证的有损复场。

主方法先计算全局平方根坐标中的32/64点Gauss结果；两者回返距离差≤0.0001 m时采用64点结果。否则，在**同一次积分调用内部**按冻结容差执行适应积分。这是开发前已定义的数值误差控制分支，不是看科研结论后更换算法或重跑实验。所有原始阶次差、适应分支选择和误差估计均保存；不再把固定32/64阶差自动等同最终参考误差。

## 3. 独立参考链

冷参考不导入主积分器：独立构造Hermite调和斜率及端点斜率、局部多项式二分求根，对每段以该段最大声速端点为平方根坐标原点并采用适应求积。它与主方法的全局转向变量、根算法及求积节点不同。两者仍共享SciPy/QUADPACK库，因此不能把它们描述为完全不同底层软件的绝对认证。

进一步以mpmath 60/80位重新从原浮点样本的精确值构造斜率、根和积分：C-linear使用高精度解析表达式，PCHIP使用tanh-sinh求积。没有将主程序的float64多项式系数转换成高精度冒充新计算。高精度结果同时保存十进制文本；60/80位差用100位Decimal从文本计算，避免先转成float后把小差吞掉。

高精度只是相同名义样本的数值参考，不增加WOA观测有效数字。求积误差估计、阶次吻合及高精度一致性都不是严格区间余项证明。最终标签是冻结有限范围内多途径数值证据，不是全部连续环境的误差定理。

## 4. 射线方程与独立核查量

另以`dz/dr=tan(alpha)`、`dalpha/dr=-c'(z)/c(z)`积分，首次向上穿越源深给回返距离，alpha=0事件给深转向点。比较距离、转向、步长细化和沿轨迹cos(alpha)/c守恒。这条路径直接积分微分方程，不能被主Snell求积的一致性替代。
