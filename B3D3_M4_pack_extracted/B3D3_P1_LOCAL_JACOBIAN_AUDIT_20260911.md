## 判定

**名义环境下，两 P1 不应被合并成一个“同方向重复时延”。**

两者都以距离敏感为主，但深度敏感项符号相反；21.9° 左右的局部夹角使联合 Jacobian 保持 rank-2。
因此在后续真实/观测约束环境重跑前，应继续同时保留两条 P1，而不是提前降为一个锚点。

但这只是**局部信息几何**。两条 P1 仍然各自只有 `7/8` 诊断环境关联，且波形提取未通过，所以有效锚点数量仍不能写成 2。

## 共享参考白化：仅条件诊断

旧 B3D-3 文档明确使用 `0.15 ms` 时延误差并计入共享参考相关性，但当前导出件没有明确保存相关系数。
若仅作为标准共享参考模型诊断，假设

```text
sigma = 0.15 ms
rho = 0.5
C = sigma² [[1, rho],
            [rho, 1]]
```

则本次两 P1 的白化奇异值为：

- `[128.605739, 41.574760]`
- 条件数：`3.0934`

**该组白化数值不是旧程序的严格复现，禁止作为正式证据。**
严格复现必须恢复旧代码中的协方差构造或在新重跑脚本中显式冻结该约定。

## 环境失配映射

现有 admission 导出只保存每个候选 `min_environment_matches = 7 / 8`，没有保存
“候选 → 具体失败扰动”的布尔矩阵。

旧 README 明确记录：`upper_plus`（上层声速正扰动）曾导致代表性参考/目标路径组合无法通过角度连续性门限。
但当前证据不足以断言 `S1B2_s1r0` 与 `S3B2_s0r1` 两者都恰好在 `upper_plus` 失败。

因此下一次成熟模型重跑必须新增：

```text
candidate × environment × range_cell
association_boolean
association_failure_reason
path_identity/eigenray_id
delay_shift
gradient_direction
```

并禁止再只输出 `7/8` 汇总计数。
